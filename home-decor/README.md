# RoomScale

Dimension-accurate 3D home décor planner. Enter room sizes, import builder
floor diagrams, place furniture to scale, and check clearances before you buy.

## Features

- Rectangular rooms with width × depth × ceiling height (metres or feet)
- Custom floor outline (polygon) for non-rectangular spaces
- Floor-plan image import with two-point calibration to a known real distance
- Furniture catalog with real-world footprint and height
- Snap-to-grid placement, rotation, dimension readout, overlap warnings

## Run under Averonsoft

Mounted at `/home-decor`. Optional CNAME: `decor.averonsoft.com`
(see `DETACH.md`).

## Standalone

```bash
npm install
npm run dev
```
