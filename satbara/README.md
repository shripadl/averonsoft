# Satbara

Maharashtra **7/12 (गाव नमुना ७/१२)** search helper. Filter by surname,
district, taluka, and/or post/village — any combination.

- Nested on Averonsoft at `/satbara`
- Detachable standalone Next.js app (see `DETACH.md`)
- Optional CNAME: `satbara.averonsoft.com`

## Local standalone

```bash
npm install
npm run dev
```

## Notes

The search index is illustrative for navigation UX. Digitally signed /
legally valid 7/12 extracts are issued via
[MahaBhulekh](https://bhulekh.mahabhumi.gov.in/).
