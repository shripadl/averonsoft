# PlotMeasure

Open-source map tool for measuring land / plot area by drawing a polygon.

## Stack (no paid licenses / API keys)

| Piece | License / notes |
|--------|------------------|
| [MapLibre GL JS](https://maplibre.org/) | BSD — map renderer |
| [OpenFreeMap](https://openfreemap.org/) | Free public vector tiles (or self-host) |
| [Turf.js](https://turfjs.org/) | MIT — geodesic area & length |
| Next.js + React | App shell |

## Local

```bash
npm install
npm run dev
```
